# rewind

> Rewind.ai-inspired screenpipe pipe — searchable timeline, automatic time tracking, and AI chat over your screen history.

## Features

- 🕐 **Timeline** — browse everything you've seen and done, with full-text keyword search
- 📊 **Time Tracking** — automatic app usage breakdown with category colors and hourly activity chart
- 💬 **Ask AI** — chat with your screen history: "What was I working on this morning?" "Did I have any meetings?"
- ⚡ **Auto snapshots** — every 30 min, sends a quick time summary to your screenpipe inbox
- 🔒 **100% local** — all data stays on your device via screenpipe

## Setup

1. Install in screenpipe
2. Add OpenAI API key in screenpipe settings
3. Make sure screenpipe is recording screen + audio
4. Open the UI and explore your history

## Tech

Next.js 14 · @screenpipe/js · Vercel AI SDK · Tailwind CSS
